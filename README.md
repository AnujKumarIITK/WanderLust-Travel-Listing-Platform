# 🌍 WanderLust – Travel & Listing Platform

> A full-stack Airbnb-inspired travel and property listing platform built with Node.js, Express, MongoDB, and modern web technologies.

---

## 🚀 Overview

**WanderLust** is a production-ready travel listing platform where users can explore destinations, create listings, upload images, and view properties on interactive maps.

This project demonstrates:
- Full-stack development
- RESTful architecture
- Cloud integrations
- Authentication & authorization
- Scalable backend structure

---

## 🛠️ Tech Stack

### 🔹 Frontend
- HTML5
- CSS3
- Bootstrap
- EJS (Templating Engine)

### 🔹 Backend
- Node.js
- Express.js

### 🔹 Database
- MongoDB
- Mongoose

### 🔹 APIs & Services
- Mapbox (Geocoding & Maps)
- Cloudinary (Image Upload & Storage)

### 🔹 Libraries & Tools
- Multer (File Upload)
- dotenv (Environment Variables)
- Joi (Validation)
- Express-session
- Connect-flash

## ⚙️ Features

### 🌐 General Features
- Explore popular travel destinations
- Clean and modern UI (Airbnb-inspired)
- Category filters (Beach, Mountains, Pools, etc.)
- Responsive design
- Toggle pricing (with/without taxes)

---

### 👤 Authentication System
- User Signup
- User Login / Logout
- Session-based authentication
- Flash messages for feedback

---

### 🏡 Listing Features
- Create new listings
- Edit listings
- Delete listings
- Upload multiple images
- View detailed listing pages

---

### 📍 Map & Location Features
- Convert location → coordinates using Mapbox
- Store GeoJSON data in MongoDB
- Display location on interactive map
